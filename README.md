# VocabLens 词镜

外语近义词**词义辨析**站 —— 查清每个词的边界、语感与用法差异，而不是只丢一堆同义词。

线上地址：https://q3yd8d39dmqgh.space.mcode.cn

## 三个模块

| 模块 | 做什么 |
| --- | --- |
| 搜索辨析 | 搜任意英文词或词组，直接看这组词的辨析：核心义、语感差异、真实例句、选词提示、易踩坑提醒 |
| 学习卡片 | 按语义分类逐组过，一组一组的边界最清楚 |
| 随堂测验 | 从真实例句和释义里挑词，做完立刻给出辨析讲解 |

另有「我的收藏」，存在本地浏览器里；「词库」页列出数据来源与规模。

## 快捷键

- `/` 聚焦搜索框
- `?` 查看帮助
- `Esc` 关闭弹层

## 数据规模

- **40 组**高频近义词辨析，覆盖 **129 个词条**、**29 个语义分类**
- 每组包含：核心义、语感差异、真实例句、选词提示、易踩坑提醒、相关表达

## 技术栈

纯静态、零构建、零依赖。`index.html` + `styles.css` + `app.js` + `data/groups.js`，
相对路径引用，整目录可直接丢到任意静态托管（Vercel / Netlify / GitHub Pages / Nginx）。
