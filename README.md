# VocabLens 词镜

英语**易混词辨析**站 —— 查清每个词的边界、语感与用法差异，而不是只丢一堆同义词。

线上地址：https://x-sky.github.io/vocablens/  （GitHub Pages 托管，地址永久固定）

## 这站收录的是「易混词」，不只是近义词

多数词组是**意思相近**，但有一类根本不是：有的差在**词性**（`affect` 动词 / `effect` 名词，
`scrutiny` 名词 / `scrutinise` 动词），有的差在**写法**（`lie` 的过去式就是 `lay`，
`few` 和 `a few` 意思几乎相反）。所以每组都标了分歧点：

| 类型 | 意思 | 组数 | 读者该先看 |
| --- | --- | --- | --- |
| 意思相近 | 都这么说，差别在用法和场合 | 32 | 语境、搭配、语体 |
| 同根异用 | 同一词根，词性不同 | 5 | 能不能放在这个位置 |
| 形近义别 | 写法几乎一样，意思却不同 | 3 | 差在哪几个字母 |

## 共核：把「为什么会混」标出来

近义词之所以难分，是因为它们**共享**一部分意思。VocabLens 会从词库里算出每一组词真正共享的片段，
并把它标出来 —— 英文标共享词素（institute / institution → `institut`），中文标共享义核（遗产 / 费用 / 改变）。

**共享处，正是最容易混淆的地方。** 看清楚共享的是什么，差异才谈得上清楚。

## 三个模块

| 模块 | 做什么 |
| --- | --- |
| 搜索辨析 | 搜任意英文词或词组，直接看这组词的辨析：核心义、语感差异、真实例句、选词提示、易踩坑提醒 |
| 学习卡片 | 按语义分类逐组过，一组一组的边界最清楚 |
| 随堂测验 | 从真实例句和释义里挑词，做完立刻给出辨析讲解 |

另有「我的收藏」，存在本地浏览器里。

## 快捷键

- `/` 聚焦搜索框
- `?` 查看帮助
- `Esc` 关闭弹层

## 数据规模

- **40 组**高频易混词辨析，覆盖 **129 个词条**、**29 个语义分类**
- 其中 **22 组**存在可标注的共核（共享词素或共享义核），**8 组**属于同根异用或形近义别
- 每组包含：核心义、语感差异、真实例句、选词提示、易踩坑提醒、相关表达

## 技术栈

纯静态、零构建、零依赖。`index.html` + `fonts.css` + `styles.css` + `app.js` + `data/groups.js`，
相对路径引用，整目录可直接丢到任意静态托管（Vercel / Netlify / GitHub Pages / Nginx）。

字体 Newsreader（SIL OFL）以 base64 内嵌在 `fonts.css`，运行时零外部请求，国内访问不受字体 CDN 影响。
